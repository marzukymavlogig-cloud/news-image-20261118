## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) validates the 1024×1024 PNG the repository holds and copies it to `$MAKEFUN_OUTPUT_DIR/entry.png`, so both graded runs write byte-identical output. The image itself (`entry.png`) was designed by the entrant's agent as HTML with inline SVG and rendered once to PNG during the build; the program ships the finished image.
